# KryxAI launch film

56-second Remotion launch film for KryxAI. No background music is included by design; only UI and motion sound effects are present.

## Render

```bash
cd launch-video
npm install
npm run studio
npm run render
```

Output: `out/kryxai-launch.mp4` (1920×1080, 60fps, H.264).

## Story

1. Introducing KryxAI — your AI Head of Marketing.
2. One goal replaces the founder juggling research, SEO, content and pipeline.
3. Kryx delegates to specialist agents and combines the evidence.
4. Mission Control keeps consequential work approval-gated.
5. Scheduled work and the shared room keep the team operating while the founder builds.
6. $0/month, pay only for work, 100 credits free, no seat fee, no expiry.
7. End card: getkryxai.com.

All operational examples are explicitly presented as a demo workspace; the film does not claim fabricated customer metrics.
