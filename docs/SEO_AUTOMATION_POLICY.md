# SEO automation policy

Daily SEO automation is allowed to research, propose and draft automatically.

It may:
- inspect the connected site/repository for technical SEO context
- research real search intent and competitor coverage
- draft one useful page when evidence supports a page
- propose title/meta/schema/internal links
- prepare a GitHub patch/PR after a scoped GitHub connector exists

It must not:
- manufacture hundreds of thin programmatic pages
- claim rankings, citations, backlinks or DR gains before measurement
- edit app code, auth, billing, infra or arbitrary files
- publish a public repository change without founder approval
- auto-submit to directories that do not explicitly allow automation

When a directory supports an API/integration and permits automated submissions, the system may prepare a submission and put it through the same founder approval gate. Otherwise it stays a manual submission task with prepared copy.
