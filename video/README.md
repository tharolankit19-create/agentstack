# KryxAI launch film

60-second, 1920×1080, 60fps Remotion launch film for KryxAI.

## Story
1. Introducing KryxAI
2. The founder problem: marketing became six jobs and seven tabs
3. Product thesis: one outcome, Kryx manages the work
4. Mission Control demo with approval interaction
5. Evidence-backed morning brief
6. Specialist system: Research, Search & Conversion, Pipeline
7. Approval rule: public / outbound / irreversible work waits for the founder
8. End card: getkryxai.com

The copy and product concepts are taken from the current apps/web product code (SITE, Hero, DemoConsole, TheArmy and army.ts) rather than invented claims.

No background music is included. The film uses small procedural UI sound effects only so a music bed can be added later.

## Render
cd video
npm install
npm run studio
npm run render

Output: video/out/kryx-launch.mp4

## Important
- The current AgentStack/KryxAI repo does not expose a committed OG image asset, so the film does not fake one.
- The film recreates the real current Kryx UI language and real product states from the repository.
- Keep this project music-free; add background music later in your editor as requested.
